# AgendaVet - Sistema de Gestão Veterinária

Sistema desenvolvido seguindo os princípios **SOLID** e utilizando **TypeScript**, aplicando padrões de projeto como *Strategy*, *Decorator*, *Adapter* e *Facade*.

## 🚀 Como Executar o Projeto

Certifique-se de ter o Node.js instalado. No terminal, na pasta raiz do projeto, execute:

```bash
# Instalar dependências (caso precise)

# Rodar a demonstração do sistema (agendamentos e listagem)
npm run dev
